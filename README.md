# Тренажёр реакции (Go/No-Go)

Веб-приложение для тренировки и измерения избирательной реакции. Пользователь реагирует на сигналы «Go» (нажать пробел) и «No-Go» (не нажимать), а приложение фиксирует время реакции и строит статистику сессии.

## Стек технологий

- **React 19** — библиотека для построения пользовательского интерфейса
- **TypeScript 6** — строгая типизация
- **Vite 8** — сборщик и dev-сервер
- **Jest** + **React Testing Library** — автоматическое тестирование
- **localStorage** — хранение истории сессий

## Требования

Перед началом убедитесь, что установлены:

- [Node.js](https://nodejs.org/) версии 18 и выше
- npm (входит в состав Node.js)

Проверить наличие:

```bash
node -v
npm -v
```

## Установка

1. Клонируйте репозиторий или распакуйте архив с проектом:

```bash
git clone https://github.com/your-username/reaction-trainer.git
cd reaction-trainer
```

2. Установите зависимости:

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

После запуска откройте браузер и перейдите по адресу:

```
http://localhost:5173/
```

## Запуск тестов

Запуск всего набора unit-тестов:

```bash
npm run test
```

Запуск в режиме наблюдения (тесты перезапускаются при изменении файлов):

```bash
npm run test:watch
```

## Сборка production-версии

```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`.

Для предварительного просмотра production-сборки локально:

```bash
npm run preview
```

## Структура проекта

```
src/
├── components/        # Компоненты интерфейса
│   ├── Controls.tsx       # Панель управления
│   ├── SignalArea.tsx      # Область отображения сигнала
│   ├── StatsPanel.tsx     # Панель статистики сессии
│   └── HistoryPanel.tsx   # История результатов
├── hooks/
│   └── useGameLogic.tsx   # Хук игровой логики
├── utils/
│   ├── signals.ts         # Генерация сигналов и конфигурации сложности
│   ├── statistics.ts      # Вычисление статистических показателей
│   ├── storage.ts         # Публичный API хранилища
│   └── database.ts        # Работа с localStorage
├── types/
│   └── index.ts           # TypeScript-типы и интерфейсы
└── App.tsx                # Корневой компонент
tests/
├── signals.test.ts        # Тесты генерации сигналов (7 кейсов)
├── statistics.test.ts     # Тесты статистики (19 кейсов)
└── storage.test.ts        # Тесты хранилища (10 кейсов)
```

## Управление

| Действие | Клавиша / элемент |
|---|---|
| Реакция на сигнал | `Пробел` |
| Запуск сессии | Кнопка «Старт» |
| Сброс сессии | Кнопка «Сброс» |
| Выбор сложности | Кнопки «Лёгкий» / «Средний» / «Сложный» |
| Выбор формы сигнала | Кнопки «Круг» / «Квадрат» / «Светофор» / «F1» |
