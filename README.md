# Тренажёр реакции (Go/No-Go)

Приложение для тренировки и измерения избирательной реакции. Проект написан на React, TypeScript и Vite.

## Что умеет приложение

- показывать случайные сигналы Go и No-Go с настраиваемой задержкой;
- фиксировать время реакции на сигнал с точностью до миллисекунды;
- считать количество попаданий, пропусков, ложных нажатий и верных отказов;
- вычислять среднее, лучшее и худшее время реакции, а также стабильность;
- сохранять историю сессий в `localStorage` браузера;
- поддерживать три уровня сложности и четыре формы сигнала.

## Выбор технологий

Проект сделан на React, TypeScript и Vite. React выбран для построения интерфейса из компонентов и удобной работы с состоянием, TypeScript помогает заранее находить ошибки в типах данных игровой логики и статистики, а Vite используется как быстрый и простой инструмент сборки для небольшого SPA-проекта.

React Router не используется, потому что в приложении нет маршрутизации между отдельными URL-страницами. Весь интерфейс отображается на одной странице: панель управления, область сигнала, статистика и история сессий расположены рядом. Такой подход проще и не добавляет зависимость, которая нужна только при наличии нескольких полноценных страниц.

Zustand и Redux Toolkit не используются, потому что всё состояние сосредоточено в одном пользовательском хуке `useGameLogic`. Передача данных через props остается понятной и достаточной для текущего масштаба приложения.

UI-библиотеки не используются, потому что интерфейс полностью описан собственными CSS-стилями. Собственная стилизация лучше подходит для учебного проекта, где важно показать понимание верстки и состояний элементов.

Для тестирования выбран Jest в связке с ts-jest. Jest — широко распространённый и хорошо документированный фреймворк, а ts-jest обеспечивает запуск TypeScript-тестов без отдельной компиляции.

## Требования

Перед запуском установите:

- Node.js;
- npm.

Проверить установку можно командами:

```bash
node -v
npm -v
```

## Установка

Перейдите в папку проекта и установите зависимости:

```bash
npm install
```

Если папка `node_modules` уже есть, этот шаг можно пропустить, но после скачивания проекта на новом компьютере зависимости нужно установить заново.

## Запуск в режиме разработки

Запустите локальный сервер:

```bash
npm run dev
```

После запуска Vite покажет адрес приложения в терминале. Обычно это:

```text
http://localhost:5173/
```

Откройте этот адрес в браузере.

## Запуск тестов

Запустить все unit-тесты:

```bash
npm run test
```

Запустить в режиме наблюдения (тесты перезапускаются при изменении файлов):

```bash
npm run test:watch
```

## Управление

| Действие | Клавиша / элемент |
|---|---|
| Реакция на сигнал | `Пробел` |
| Запуск сессии | Кнопка «Старт» |
| Сброс сессии | Кнопка «Сброс» |
| Выбор сложности | Кнопки «Лёгкий» / «Средний» / «Сложный» |
| Выбор формы сигнала | Кнопки «Круг» / «Квадрат» / «Светофор» / «F1» |

## Данные

Приложение хранит историю сессий в `localStorage` браузера под ключом `reaction-trainer-history`. Серверная база данных не используется. Максимальное количество хранимых сессий — 50.

Если открыть приложение в другом браузере или очистить данные сайта, история сессий будет недоступна.
